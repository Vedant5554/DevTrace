## Overview

DevTrace is a client-side algorithm visualization platform engineered to demonstrate data structure operations and algorithm mechanics through deterministic state transitions.

Traditional visualizers often rely on lossy CSS animations, imperative timeouts, or unmanaged asynchronous delays, making reliable backward stepping difficult. DevTrace models algorithm execution as an inspectable, discrete event timeline. Every snapshot is generated by pure, deterministic engine functions, enabling seamless forward execution, reverse stepping, frame scrubbing, and instant state recovery without recalculation drift or desynchronization.

In addition to the visual player, each algorithm page contains a comprehensive technical reference featuring complexity metrics, chronological step breakdowns, worked state tables, practical trade-offs, and multi-language reference implementations.

---

## Key Highlights

- **Deterministic & Reversible Playback Engine**: Complete step-by-step control. Advance forward, pause, or step backward with exact state reconstruction at every frame.
- **Pure Algorithm Generators**: Algorithms are isolated as pure generator functions that emit structured event frames, keeping visual representation decoupled from algorithmic logic.
- **Client-Side Architecture**: Zero server dependencies. Runs completely in modern web browsers as a high-performance Single Page Application (SPA).
- **URL-Synchronized Player State**: View mode, execution speed, and dataset size persist in query parameters (`?view=&speed=&size=`) for reproducible sharing and classroom demonstrations.
- **Rigorous Technical Reference Articles**: Each visualization includes an 8-part educational write-up:
  - Conceptual Foundation and Intuitive Mechanics
  - Asymptotic Complexity Analysis (Best, Average, Worst Time and Space)
  - Chronological Step-by-Step Action Sequence
  - Worked State Trace Table (tracking pointers, visited sets, stack/queue snapshots)
  - Trade-off Matrix (When to Choose vs. When to Avoid)
  - Syntax-Clean Reference Implementations across 5 Languages (Python, JavaScript, Java, C++, C)
  - Common Pitfalls, Edge Cases, and FAQs
  - Sibling Algorithm Navigation
- **Domain Hubs and Comparison Matrices**: Section landing pages featuring domain-specific comparison tables for complexity and operational trade-offs.
- **Tested Test Suite**: Over 220 unit, component, algorithm, and integration pipeline tests executed with Vitest.

## Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- Node.js (version 18.0.0 or higher)
- npm (bundled with Node) or pnpm / yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/VedantGavate/FSD-DevTrace.git
   cd FSD-DevTrace
   ```

2. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

3. Install project dependencies:
   ```bash
   npm install
   ```

4. Launch the local development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

## Verification and Testing

DevTrace includes a comprehensive suite of unit, component, and integration tests across all algorithm generators, playback controllers, and UI components.

To run the test suite:
```bash
cd frontend
npm test -- --run
```

To run tests in interactive watch mode:
```bash
cd frontend
npm test
```

To execute ESLint static analysis:
```bash
cd frontend
npm run lint
```

To verify the production build:
```bash
cd frontend
npm run build
```
